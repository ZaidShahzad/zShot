# Always running, with Screenshot mode built ahead of time

To hit the speed targets (Capture hotkey to crosshair in under 50 ms), zShot starts at login, lives only in the menu bar, and builds the Screenshot mode windows at launch, keeping them hidden until the Capture hotkey is pressed. Pressing the hotkey only shows windows that already exist. Annotations are drawn directly in Screenshot mode rather than in a separate editor window, so finishing a Screenshot never waits for a new window to open.
